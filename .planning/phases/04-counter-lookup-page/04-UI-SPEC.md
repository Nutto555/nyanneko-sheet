## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, condition badge internal padding, portrait-to-name gap |
| sm | 8px | Compact element spacing, badge row gaps, inline card padding |
| md | 16px | Default element spacing, card internal padding, input margins |
| lg | 24px | Section padding, result card padding, template grid gap |
| xl | 32px | Layout gaps between page sections (search area to results) |
| 2xl | 48px | Major section breaks (header to template grid, template grid to results) |
| 3xl | 64px | Page top/bottom padding (`py-16`) |

Exceptions: Character portrait sizes use non-standard values (32px, 48px, 72px) as established by `CharacterPortrait` SIZE_MAP. These are image dimensions, not spacing tokens.

## Typography

All values use Sarabun (body font) unless noted as Cinzel (display font).

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body | 14px (`text-sm`) | 400 | 1.5 | Sarabun |
| Label | 12px (`text-xs`) | 600 | 1.4 | Sarabun |
| Heading | 20px (`text-xl`) | 600 | 1.2 | Sarabun |
| Display | 28px (`text-2xl`) | 600 | 1.2 | Cinzel |

Usage in this phase:
- **Display**: Page title "Counter Lookup" at top of `/counter`
- **Heading**: Each counter result card title (enemy template name), section headers ("Featured Defenses", "Results")
- **Label**: Condition badges ("If enemy has X"), match indicators ("3/4 matched"), priority rank labels ("Priority 1"), `updated_at` timestamps
- **Body**: Strategy notes, condition notes, empty state text, error messages

## Component Inventory

Components created in this phase, with their visual contracts:

### EnemyTemplateGrid

- Layout: CSS grid, `grid-cols-2 sm:grid-cols-3 lg:grid-cols-4`, gap `24px`
- Each card: `Card` component (existing), shows 4-6 `CharacterPortrait` at size `sm` (32px) in a horizontal row, template name below in Heading weight
- Clicked state: border changes to `border-primary/50`, subtle `shadow-primary/10`
- Featured indicator: gold dot or star icon using `--color-gold`

### CounterResultCard

- Container: `Card` component with `p-6`, no hover effect (`hover={false}`)
- Header row: Enemy template name (Heading, 20px, weight 600) left-aligned, match indicator right-aligned
- Match indicator: "Exact match" in `text-green-400` or "3/4 matched" in `text-amber-400`, Label size
- Enemy team portraits: horizontal row of `CharacterPortrait` at size `md` (48px), gap `8px`
- Divider: `border-t border-white/6` between enemy team display and strategy list
- Strategy list: vertical stack of `StrategyCard` sub-components, gap `16px`

### StrategyCard

- Container: `bg-surface-raised rounded-lg p-4 border border-white/6`
- Priority badge: circular `w-6 h-6 rounded-full bg-primary/20 text-primary-light text-xs font-semibold` with number centered, top-left
- Counter team: horizontal row of `CharacterPortrait` at size `md` (48px) with names shown (`showName={true}`), gap `8px`
- Conditions: `ConditionBadges` component below team, gap `8px`
- Notes: strategy_notes rendered as Body text in `text-gray-400`, below conditions, gap `8px`
- Timestamp: `updated_at` formatted as relative or date, Label size, `text-gray-500`, bottom-right

### ConditionBadges

- Layout: `flex flex-wrap gap-1`
- Must-have badge: `inline-flex items-center px-2 py-0.5 rounded-full text-xs font-medium border bg-green-900/30 text-green-300 border-green-700/30`
- Copy pattern: "If enemy has {name_en}"
- Must-not-have badge: same shape, `bg-red-900/30 text-red-300 border-red-700/30`
- Copy pattern: "If enemy lacks {name_en}"
- Each badge optionally includes a `CharacterPortrait` at size `sm` (32px) inline before the text

## Interaction States

### Page Load
- Show skeleton loader for template grid (3 placeholder cards, pulse animation)
- Show skeleton for character selector area
- Use existing `animate-pulse` pattern from `GvgMode.tsx` TeamSkeleton

### No Selection (Default State)
- Featured templates grid visible at top
- Character selector visible with placeholder
- Results section hidden (not empty state -- just absent)

### Active Search (Characters Selected)
- Featured template grid collapses/hides
- Selected characters visible as chips in `CharacterMultiSelect`
- Results appear below, grouped: "Exact Matches" section first, then "Partial Matches"
- If zero results with matchScore > 0: show empty state

### Template Click
- Populate `CharacterMultiSelect` with template's characters
- Trigger search immediately (same as manual selection)
- Featured grid hides, results appear

### Clear Selection
- "Clear" button appears when characters are selected
- Clicking returns to default state (featured templates visible again)

## Accessibility

| Requirement | Implementation |
|-------------|---------------|
| Keyboard navigation | Template cards focusable via Tab, activated via Enter/Space |
| Screen reader | Each counter result card has `aria-label` describing enemy comp and match quality |
| Color contrast | All text meets WCAG AA against dark backgrounds (green-300 on green-900/30 = ~5.2:1, red-300 on red-900/30 = ~5.0:1) |
| Condition semantics | Badges use `role="status"` so screen readers announce conditions |
| Focus visible | Focus ring uses `ring-2 ring-primary/50 ring-offset-2 ring-offset-bg` |
