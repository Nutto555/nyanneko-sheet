Replace the stub implementations in `src/utils/strategyMatcher.ts` with working logic.

**`evaluateStrategy` implementation (per D-06):**

1. Extract `must_have` conditions: `strategy.strategy_conditions.filter(c => c.condition_type === 'must_have')`
2. Extract `must_not_have` conditions: `strategy.strategy_conditions.filter(c => c.condition_type === 'must_not_have')`
3. Create a `Set<string>` from `enemyCharacterIds` for O(1) lookup
4. Check all must_have: every must_have condition's `character_id` must be in the enemy set. If any is missing, return `false`.
5. Check all must_not_have: every must_not_have condition's `character_id` must NOT be in the enemy set. If any is present, return `false`.
6. If both checks pass, return `true`.
7. If strategy has zero conditions, return `true`.

**`resolveMatchingStrategies` implementation (per D-03, D-04, D-05):**

1. Create a `Set<string>` from `enemyCharacterIds`
2. For each template in `templates`:
   a. Compute `matchedCharacterIds`: template's `enemy_defense_members` whose `character_id` is in the enemy set. Collect the matching character_id strings.
   b. Compute `matchScore`: `matchedCharacterIds.length / template.enemy_defense_members.length`. If template has 0 members, score is 0.
   c. Filter strategies for this template: `strategies.filter(s => s.template_id === template.id)`, then filter by `evaluateStrategy(s, enemyCharacterIds)`, then sort by `priority` ascending.
   d. Build `MatchResult` object with template, matchScore, matchedCharacterIds, and the filtered+sorted strategies.
3. Sort all results: by `matchScore` descending, then by `template.sort_order` ascending as tiebreaker (per D-05).
4. Return the sorted array. Include ALL templates — no minimum threshold (per D-04).

**Important:** The file must contain ONLY imports from `../types/database` (type imports). No imports from `../lib/supabase`, `../services/*`, `react`, or any runtime dependency. This is a pure utility.
