- Props interface `PageHeaderProps`: `{ title: string; subtitle?: string; className?: string }`
- Renders:
  - `<div className={`mb-8 ${className}`}>`
  - `<h1 className="text-2xl font-bold text-white" style={{ fontFamily: 'var(--font-display)' }}>{title}</h1>`
  - If subtitle: `<p className="text-sm text-slate-400 mt-2">{subtitle}</p>`

**Skeleton.tsx** (named exports `Skeleton`, `SkeletonCard`, `SkeletonText`):
- `Skeleton` base primitive: Props `{ className?: string; style?: React.CSSProperties }`. Renders `<div className={`animate-skeleton rounded ${className}`} style={{ background: 'var(--color-surface-raised)', ...style }} />`
- `SkeletonText`: Props `{ lines?: number; className?: string }`. Renders `lines` (default 3) skeleton bars — first line `w-3/4 h-4`, remaining lines `w-full h-3`, last line `w-1/2 h-3`. Each has `mb-2` gap.
- `SkeletonCard`: Props `{ className?: string }`. Renders a card-shaped skeleton: `rounded-xl overflow-hidden` with `border: 1px solid var(--color-border)`, `background: var(--color-surface)`. Inside: a portrait placeholder (w-16 h-16 rounded-lg) + SkeletonText with 2 lines.
- All skeleton elements use `var(--color-surface-raised)` for the shimmer bars (NOT gray — per D-04 dark theme requirement)
