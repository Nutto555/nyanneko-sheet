# NyanNeko Sheet 🐱⚔️

A Guild vs Guild (GvG) guide platform built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- GvG Strategy Guides
- Team Compositions
- Tier Lists
- Gear Sheets & Optimization

## Tech Stack

- **React 19** + **TypeScript**
- **Vite** (build tool)
- **Tailwind CSS v4** (styling)
- **React Router v7** (routing)

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Project Structure

```
src/
├── components/
│   ├── layout/      # Navbar, Footer, Layout
│   ├── ui/          # Reusable UI components (Card, Badge, Button)
│   └── common/      # Shared components
├── pages/           # Route pages (Home, Guides, Compositions, etc.)
├── hooks/           # Custom React hooks
├── utils/           # Utility functions
├── types/           # TypeScript type definitions
└── assets/          # Static assets
```
